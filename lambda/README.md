# JD Dental Lab — Scan Conversion Lambda

S3-triggered AWS Lambda that converts raw intraoral scans (**STL / PLY / OBJ-zip**)
uploaded under `scans/raw/` into small, decimated, **Meshopt-compressed GLB**
files written to `scans/glb/`, so the portal viewer never loads 70–150 MB raw
meshes. It reuses the same pure-Node `convertScan()` core as the app (vendored
here at package time).

- Entry point: [`handler.mjs`](handler.mjs) → exported `handler`
- Conversion core: `convert-scan.mjs` (vendored from `../scripts/convert-scan.mjs`)
- Runtime: **Node.js 22**, arm64, 4096 MB, 300 s timeout
- IAM / S3 wiring: [`aws/`](aws/) (trust policy, S3 read/write policy, bucket notification)

> `node_modules/`, the vendored `convert-scan.mjs`, and `lambda.zip` are build
> artifacts — **gitignored**, regenerated by `npm run bundle`. Not committed.

---

## Build the deployment bundle

Lambda ships its dependencies **inside the zip** (it never runs `npm install`),
so packaging is: vendor the converter core → install prod deps → zip.

```bash
cd lambda
npm run bundle    # = npm run vendor (copy ../scripts/convert-scan.mjs) + npm install --omit=dev
```

Then create the zip (contents: handler + vendored core + package.json + deps):

**bash (AWS CloudShell / Linux / macOS)**
```bash
zip -r ../lambda.zip handler.mjs convert-scan.mjs package.json node_modules >/dev/null
```

**PowerShell (Windows)**
```powershell
$env:NODE_USE_ENV_PROXY='1'   # corporate proxy, so npm can fetch
npm run bundle
Compress-Archive -Path handler.mjs, convert-scan.mjs, package.json, node_modules `
  -DestinationPath ..\lambda.zip -Force
```

The zip contains ONLY: `handler.mjs`, `convert-scan.mjs`, `package.json`,
`node_modules/`. It deliberately excludes `aws/` (deploy-time config, not runtime),
`package-lock.json`, and `@aws-sdk/client-s3` (provided by the Node 22 runtime —
it's a devDep, so `--omit=dev` keeps it out and the zip stays lean).

## First-time deploy

Set variables (CloudShell already has creds):
```bash
SCAN_BUCKET=your-scan-bucket
DEPLOY_BUCKET=$SCAN_BUCKET            # can reuse the scan bucket to stage the zip
REGION=${AWS_REGION:-us-east-1}
ACCOUNT_ID=$(aws sts get-caller-identity --query Account --output text)
```

1. **Stage the zip in S3** (it's >50 MB — can't upload inline):
   ```bash
   aws s3 cp ../lambda.zip s3://$DEPLOY_BUCKET/lambda/jdlab-scan-convert.zip
   ```
2. **IAM role** (fill in the bucket, then create):
   ```bash
   sed -i "s|<SCAN_BUCKET>|$SCAN_BUCKET|g" aws/s3-read-write-policy.json
   aws iam create-role --role-name jdlab-scan-convert \
     --assume-role-policy-document file://aws/trust.json
   aws iam attach-role-policy --role-name jdlab-scan-convert \
     --policy-arn arn:aws:iam::aws:policy/service-role/AWSLambdaBasicExecutionRole
   aws iam put-role-policy --role-name jdlab-scan-convert \
     --policy-name scan-s3-rw --policy-document file://aws/s3-read-write-policy.json
   ```
3. **Create the function:**
   ```bash
   aws lambda create-function --function-name jdlab-scan-convert \
     --runtime nodejs22.x --handler handler.handler \
     --role arn:aws:iam::$ACCOUNT_ID:role/jdlab-scan-convert \
     --code S3Bucket=$DEPLOY_BUCKET,S3Key=lambda/jdlab-scan-convert.zip \
     --memory-size 4096 --timeout 300 --architectures arm64 --region $REGION
   ```
4. **Allow S3 to invoke it:**
   ```bash
   aws lambda add-permission --function-name jdlab-scan-convert \
     --statement-id s3invoke --action lambda:InvokeFunction \
     --principal s3.amazonaws.com \
     --source-arn arn:aws:s3:::$SCAN_BUCKET --region $REGION
   ```
5. **Wire the S3 trigger** (filters `scans/raw/` + `.stl`/`.ply`/`.zip`):
   ```bash
   sed -i "s|<REGION>|$REGION|g; s|<ACCOUNT_ID>|$ACCOUNT_ID|g" aws/s3-notify.json
   aws s3api put-bucket-notification-configuration --bucket $SCAN_BUCKET \
     --notification-configuration file://aws/s3-notify.json
   ```
6. **Test:**
   ```bash
   aws s3 cp ../test-fixtures/sample-scan.stl s3://$SCAN_BUCKET/scans/raw/test.stl
   sleep 8
   aws s3 ls s3://$SCAN_BUCKET/scans/glb/        # expect test.glb
   aws logs tail /aws/lambda/jdlab-scan-convert --since 5m --region $REGION
   ```

## Redeploy after a code change

```bash
npm run bundle
zip -r ../lambda.zip handler.mjs convert-scan.mjs package.json node_modules >/dev/null
aws s3 cp ../lambda.zip s3://$DEPLOY_BUCKET/lambda/jdlab-scan-convert.zip
aws lambda update-function-code --function-name jdlab-scan-convert \
  --s3-bucket $DEPLOY_BUCKET --s3-key lambda/jdlab-scan-convert.zip --region $REGION
```

|-----|---------|---------|

| `TARGET_TRIS` | converter default (350k) | triangle budget |
